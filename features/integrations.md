# Интеграции: действия прямо из диалога

Интеграции NN Agent позволяют агенту не только разговаривать, но и делать. Прямо из диалога он записывает на встречу в календаре, обновляет карточку в вашей CRM, выставляет счёт и возвращается к собеседнику с результатом.

## Что подключается

- **CRM** — Bitrix24, AmoCRM. Коннекторы к HubSpot, Salesforce и n8n заявлены как ближайшие релизы.
- **Календари** — Google Calendar для назначения встреч.
- **Таблицы** — Google Sheets для чтения и записи строк, отчётов.
- **Платежи** — Stripe, ЮKassa: счёт создаётся прямо из чата.
- **Любые внешние API** — через вызовы инструментов и webhook.

Каталог инструментов берётся из Dify: более 800 готовых интеграций или ваши собственные.

## Как выглядит вызов из диалога

Сценарий описывает цепочку узлов: квалификация, определение намерения, вызов инструмента. Например, после согласия на демо агент вызывает создание сделки в AmoCRM, затем создание события в Google Calendar, при необходимости — создание платежа. Результат каждого шага возвращается в диалог.

Менеджер в этой цепочке не участвует: он видит уже назначенную встречу и обновлённую карточку.

## Автоматизации без кода

Помимо прямых коннекторов NN Agent заявлен как интегрируемый со стеком автоматизаций: n8n, Make, Zapier, ClawBot, OpenAI. Это тот же принцип — агент дергает внешний сервис как инструмент.

## Если нужна интеграция в свой интерфейс

Обратный сценарий — не NN Agent ходит в ваши сервисы, а ваш продукт управляет NN Agent. Для этого есть API: аккаунты и переписка синхронно, AI ведёт диалоги по вашим скриптам, управление остаётся в вашем интерфейсе. Начните с [обзора API](../api/overview.md).
