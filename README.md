# NN Agent: кабинет, AI-агенты и API для исходящих продаж

NN Agent — движок исходящих продаж в Telegram и WhatsApp. Аккаунты мессенджеров, переписка и воронка живут в одном кабинете: AI инициирует диалог по вашей базе контактов, ведёт его по вашему сценарию и передаёт менеджеру там, где нужен человек.

Продукт разворачивается в двух видах. **NN Agent CRM** — готовый кабинет для отдела продаж, подключение занимает несколько минут через Telegram-бот. **NN Agent API** — тот же движок под вашим интерфейсом: вы держите свою CRM, а приём и отправку сообщений, аккаунты и кампании отдаёте NN Agent.

## Что делает NN Agent иначе

**Живые аккаунты, а не боты.** Каждый подключённый аккаунт остаётся полноценным аккаунтом мессенджера с именем, фото и историей диалогов, а не ботом с кнопкой «Start».

**Собственный движок коммуникаций.** Приём и отправка в мессенджерах — своя инфраструктура NN Agent, а не обёртка над чужим сервисом рассылок.

**AI ведёт диалог целиком.** От первого сообщения до квалификации и назначения встречи. Менеджер подключается там, где решение за человеком.
