# Обзор API NN Agent

API NN Agent даёт вашему продукту то же, что кабинет даёт менеджеру: подключение аккаунтов мессенджеров, кампании, контакты и переписку. Управление при этом остаётся в вашем интерфейсе.

Базовый адрес: `https://api.nexifyneo.com`

## Что доступно через API

| Группа | Что делает | Страница |
|---|---|---|
| Клиент и лицензии | Данные учётной записи, активация и продление лицензий | [Ниже на этой странице](#клиент-и-лицензии) |
| Аккаунты и сессии авторизации | Подключение и отключение аккаунтов мессенджеров | [Аккаунты](./accounts.md) |

| Диалоги | Чтение переписки и отправка сообщений | [Диалоги](./dialogs.md) |

Всего опубликованная спецификация объявляет 96 операций: 35 в версии `v2`, 60 в версии `v1` и служебная проверка состояния.

## Версии v1 и v2

`v2` — текущая версия. Она построена по ресурсной схеме: сущность в пути, действие в HTTP-методе. `v1` осталась от предыдущего поколения, где действие вынесено в путь.

| Задача | v1 | v2 |
|---|---|---|
| Список кампаний | `GET /v1/campaign_list/{client_id}` | `GET /v2/campaigns` |
| Создать кампанию | `POST /v1/create_campaign` | `POST /v2/campaigns` |
| Обновить кампанию | `POST /v1/update_campaign` | `POST /v2/campaigns/{campaign_id}/update` |
| Удалить кампанию | `DELETE /v1/campaign` | `DELETE /v2/campaigns/{campaign_id}` |
| Отправить сообщение | `POST /v1/accounts/{account_id}/dialogs/send` | `POST /v2/accounts/{account_id}/dialogs/{peer_user_id}/messages` |
| Загрузить контакты | `POST /v1/contacts/upload/csv` и `/excel` | `POST /v2/campaigns/{campaign_id}/contacts/upload?format=csv\|xlsx` |

Главное отличие на практике: в `v2` идентификатор клиента не передаётся в пути — его определяет токен. В `v1` многие операции требуют `client_id` явным параметром.

**Начинайте с `v2`.** К `v1` обращайтесь, если у вас уже есть работающая интеграция или нужен парсер: он опубликован только в `v1`. Полный перечень — [Справочник v1](./v1-reference.md).

## Клиент и лицензии

<!-- widget:api -->

## GET /v2/client

Данные учётной записи, к которой привязан токен.

## GET /v2/client/licenses

Список лицензий клиента: активные слоты и сроки.

Активировать лицензию по коду. Тело запроса — JSON.

## Известные ограничения

**TLS-сертификат хоста `api.nexifyneo.com` самоподписанный.** Браузер и большинство HTTP-клиентов по умолчанию отклоняют соединение с ошибкой проверки сертификата. Пока сертификат не заменён на выданный публичным центром сертификации, интерактивные запросы со страницы и обращения из строгих клиентов не пройдут. Уточните текущий статус у менеджеров в боте `@NN_official_bot`.

**Тела запросов не типизированы в спецификации.** Опубликованный документ OpenAPI описывает тела POST-запросов как свободный JSON-объект, без перечня полей. На страницах справочника указано то, что спецификация действительно объявляет: метод, путь, параметры пути и запроса. Точный состав тела уточняйте у менеджеров в боте.
